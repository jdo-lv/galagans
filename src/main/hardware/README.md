# Hardware

Firmware for physical devices, one folder per device. Each is a PlatformIO project, outside the Maven build.

| Folder | Device | What it does |
|---|---|---|
| [dot-display](dot-display/README.md) | Waveshare ESP32-C6-Touch-LCD-1.47 (also builds for the S3 version) | Shows a 0–100 % value as 1–6 dots coloured by alert level; dev mode loops a 90 s scenario |
